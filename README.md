# Preposition Quest CT

Игровой тренажёр выражений с предлогами для подготовки к ЦТ. Проект не требует сборки: `index.html` находится в корне пакета и подходит для GitHub Pages.

## Что работает

- 35 тематических карточек;
- более 1 100 выражений, извлечённых из предоставленного PDF;
- последовательное открытие карточек;
- по 20 случайных заданий;
- сопоставление с переводом, выбор ответа и ввод пропуска;
- проходной результат 80%;
- повторение ошибок;
- 7 контрольных тестов;
- адаптивный дизайн;
- вход ученика по имени и личному коду;
- вход преподавателя по email и паролю;
- создание учеников и генерация кодов;
- облачное сохранение прогресса в Firebase;
- кабинет преподавателя со списком учеников.

## Как загрузить на GitHub

1. Создайте новый пустой репозиторий.
2. Загрузите **содержимое** этой папки в корень репозитория. Файл `index.html` должен лежать в корне, а не внутри дополнительной папки.
3. Откройте `Settings` → `Pages`.
4. В разделе `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`.
6. Нажмите `Save` и подождите публикацию.

## Обязательная настройка Firebase

1. В Firebase Console откройте Authentication → Sign-in method и включите Email/Password.
2. В Authentication → Settings → Authorized domains добавьте `lukshaolga1982-ship-it.github.io`.
3. Создайте Firestore Database в Production mode.
4. Откройте Firestore Database → Rules, вставьте содержимое `firestore.rules` и нажмите Publish.
5. В Authentication → Users создайте аккаунт преподавателя с вашим email и паролем.
6. Скопируйте UID этого аккаунта.
7. В Firestore создайте коллекцию `teachers`, документ с именем, равным UID, и поле `displayName` со значением `Olga`.

После этого войдите на сайт как преподаватель и создавайте учеников. Не размещайте в репозитории файл сервисного аккаунта или private key.
